## Hi, I'm Dean

Student, currently learning to build things properly rather than just make

**What I'm working on**

- [study-timer](https://github.com/vampirebergs/study-timer) — a Pomodoro
  timer for the terminal. Zero dependencies, and the planning logic is kept
  separate from the clock so the tests do not have to wait 25 minutes.
- [split-the-bill](https://github.com/vampirebergs/split-the-bill) — takes a
  CSV of a trip's expenses and prints the short list of payments that squares
  everyone up. Greedy settling, money handled in whole cents.
- [todo-board](https://github.com/vampirebergs/todo-board) — a three-column
  todo board as one static page, no framework.
  [Try it](https://vampirebergs.github.io/todo-board/).

**How I like to work**
